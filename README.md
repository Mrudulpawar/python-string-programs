# python-string-programs

This repository contains a collection of beginner-friendly Python programs based on **strings, loops, and conditional statements**.

These programs were created for Python practice and help in understanding basic programming concepts such as `for` loops, `if-else`, string operations, and user input.

## Programs Included

### 1. Reverse a String

Reverses a given string without using the reverse function.

**Example:**

```text
Original string: India
Reverse string: aidnI
```

### 2. Check Palindrome String

Checks whether a given string is a palindrome or not.

**Example:**

```text
Input: madam
Output: Palindrome
```

### 3. Count Vowels in a String

Counts the number of vowels present in a given string.

**Example:**

```text
Input: pawar
Output: vowels = 2
```

### 4. Count Consonants in a String

Counts the number of consonants present in a given string.

**Example:**

```text
Input: pawar
Output: consonants = 3
```

### 5. Count Vowels and Consonants

Counts both vowels and consonants from a given string.

**Example:**

```text
Input: pawar

Output:
vowels = 2
consonants = 3
```

### 6. Count String Length Without `len()`

Finds the length of a string using a `for` loop without using the built-in `len()` function.

**Example:**

```text
Input: pawar
Output: 5
```

### 7. Check Whether a Character is Present

Checks whether a particular character exists in a given string.

**Example:**

```text
Input: Python
Character: P

Output:
Character is present
```

### 8. Check Whether Two Strings are Equal

Compares two strings and checks whether they are equal or not.

**Example:**

```text
Input:
First string: Hello
Second string: Python

Output:
Strings are not equal
```

### 9. Find the Largest Number

Takes three numbers as input and finds the largest number using `if-elif-else`.

**Example:**

```text
Input:
10
25
15

Output:
Largest number is: 25
```
